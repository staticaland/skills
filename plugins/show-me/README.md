# show-me

Explain the topic at hand visually with diagrams, code-shape sketches, and
focused HTML.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install show-me@staticaland-skills
```

## Skills

- **[show-me](./skills/show-me/SKILL.md)** (skill) - Picks the smallest view
  that makes the point - pseudocode, a call tree, a component tree, a file
  tree, a Mermaid diagram, a diff, or one focused HTML file - and places it
  next to short prose.
