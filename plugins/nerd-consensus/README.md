# nerd-consensus

Find what enthusiast communities agree on, argue about, and warn against for a
product, tool, or product category.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install nerd-consensus@staticaland-skills
```

## Skills

- **[nerd-consensus](./skills/nerd-consensus/SKILL.md)** (skill) - Researches
  the forums, subreddits, and wikis of the communities that obsess over a
  product or category, and reports the consensus, the contested points, and
  the known flaws, with sources.
