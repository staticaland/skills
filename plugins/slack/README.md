# slack

Write Slack messages in Slack's own markup: single-asterisk bold, hyphen lists,
and no headings or tables.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install slack@staticaland-skills
```

## Skills

- **[slack-messages](./skills/slack-messages/SKILL.md)** (skill) - Writes a
  message to paste into Slack, in Slack's markup instead of standard Markdown,
  inside one code block to copy.
