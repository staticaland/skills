# polish-ui

Review a UI for visual polish and fix the alignment, spacing, grouping,
typography, emphasis, and colour issues it finds.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install polish-ui@staticaland-skills
```

## Skills

- **[polish-ui](./skills/polish-ui/SKILL.md)** (skill) - Checks a page,
  component, or screenshot against a list of visual-polish criteria, from
  alignment and overflow to visual weight and the squint test, then names and
  fixes each issue.
