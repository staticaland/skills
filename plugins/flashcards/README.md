# flashcards

Turn text, notes, code, or images into Anki flashcards built on Andy
Matuschak's prompt-writing principles.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install flashcards@staticaland-skills
```

## Skills

- **[anki-flashcards](./skills/anki-flashcards/SKILL.md)** (skill) -
  Creates concise Anki flashcards from text, documents, or images for spaced
  repetition learning.
