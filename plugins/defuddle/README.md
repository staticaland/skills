# defuddle

Extract clean Markdown from web pages with the Defuddle CLI, without the
navigation, ads, and clutter.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install defuddle@staticaland-skills
```

## Skills

- **[defuddle](./skills/defuddle/SKILL.md)** (skill) - Reads a web page with
  [Defuddle](https://github.com/kepano/defuddle) instead of a plain fetch, so
  the agent gets the page's content as Markdown, or one metadata field,
  for fewer tokens.
