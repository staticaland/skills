# pasta

Cook spaghetti pomodoro two ways: a quick garlic and olive oil sauce, and
Marcella Hazan's slow tomato, butter, and onion sauce.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install pasta@staticaland-skills
```

## Skills

- **[pomodoro-garlic-oil](./skills/pomodoro-garlic-oil/SKILL.md)** (skill) -
  Walks through a bright 30-minute spaghetti pomodoro with garlic, olive oil,
  and basil.
- **[pomodoro-butter-onion](./skills/pomodoro-butter-onion/SKILL.md)**
  (skill) - Walks through Marcella Hazan's slow tomato, butter, and onion
  sauce over spaghetti.
