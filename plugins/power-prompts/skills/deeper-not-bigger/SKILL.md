name: deeper-not-bigger
description: Rewrite a prompt to ask for the deeper version of a task, the way a top professional would do it.
disable-model-invocation: true
---

<!-- The prompt is quoted verbatim. -->

I want a deeper version of this task, not a bigger one. Before rewriting it:
(1) say what a top professional in this field would do here that I'm not asking
for; (2) name the rawest material they would start from instead of what has
already been digested for me; (3) name the specific methods and tools they would
use; (4) say what, other than you or me, would show the result is right. Then
rewrite my prompt to ask for exactly that.

Apply it to the prompt the user gives with this command, or else to the task at
hand in this conversation.
