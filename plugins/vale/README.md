# vale

Act on Vale alerts like an editor: rewrite the sentence or suppress the one
rule, and keep the vocabulary to real spelling needs.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install vale@staticaland-skills
```

## Skills

- **[vale-alerts](./skills/vale-alerts/SKILL.md)** (skill) - Gives each
  [Vale](https://vale.sh/) alert a verdict - rewrite or suppress - and
  separates spelling allowlist entries from terms that belong in backticks.
