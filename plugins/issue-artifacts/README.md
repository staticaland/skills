# issue-artifacts

Attach plans, notes, HTML documents, and links to a GitHub issue as issue
artifacts with `gh`, and read, edit, version, download, and delete them.

## Install

```text
/plugin marketplace add staticaland/skills
/plugin install issue-artifacts@staticaland-skills
```

## Skills

- **[gh-issue-artifact](./skills/gh-issue-artifact/SKILL.md)** (skill) -
  Manages the Markdown documents, HTML documents, and links attached to a
  GitHub issue with `gh issue artifact`: create, list, view, edit, restore a
  version, download, and delete.
